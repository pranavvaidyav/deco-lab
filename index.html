Educational Theory & Logic Analysis

Understand the fundamental principles of binary arithmetic and logic gate operations.

What is a Half Adder?

A Half Adder is a basic combinational logic circuit designed to perform the addition of two single-bit binary numbers ($A$ and $B$).

It generates two distinct binary outputs:

  • SUM ($S$): The least significant bit (LSB) of the addition.
  • CARRY ($C$): The most significant bit (MSB), generated when both inputs are HIGH ($1$).
Important Note: A Half Adder does not accept a Carry-In ($C_{in}$) signal from a previous addition stage.

XOR Gate (Exclusive OR)

Generates SUM Output
SUM = A ⊕ B = A'B + AB'

The XOR gate evaluates to HIGH (1) if and only if the two inputs are different from each other.

A=0, B=0 → 0
A=0, B=1 → 1
A=1, B=0 → 1
A=1, B=1 → 0

AND Gate

Generates CARRY Output
CARRY = A · B

The AND gate evaluates to HIGH (1) only when both inputs $A$ and $B$ are simultaneously HIGH (1).

A=0, B=0 → 0
A=0, B=1 → 0
A=1, B=0 → 0
A=1, B=1 → 1
